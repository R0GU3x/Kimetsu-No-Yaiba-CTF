# 鬼滅CTF — Kimetsu no Yaiba Capture The Flag

Welcome to **鬼滅CTF**, a browser-based Capture The Flag experience inspired by **Kimetsu no Yaiba**.

## 🚀 Getting Started

Launching the application is simple:

1. Open **`index.html`** in your web browser.
2. The application starts immediately—no additional setup is required.

## 🌐 Internet Connection

Please ensure you have a **stable internet connection** for a seamless experience. Some assets and game functionality depend on uninterrupted connectivity.

## 🎯 Mission

Digital demons have emerged.

Your mission is to stay alive, solve the challenges, and save the world from the digital demons.

Good luck, Slayer.
